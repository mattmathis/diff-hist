# M-Lab Differential Histogram Measurement Notebooks

These notebooks measure Internet quality globally by detecting anomalous
topology, routing policies, and congested interconnects in mid-path Interconnections between ISPs.

See:
- The paper [Detecting Anomalous Topology, Routing Policies, and Congested
Interconnections at Internet Scale](https://arxiv.org/abs/2603.25875);
- A short presentation deck, [Annealing the Internet (Lite)](https://docs.google.com/presentation/d/1NtlXFFAkwF5HqHWcDcrbh3TrGUdpdHKa1AWJ404kLQ4/edit?usp=sharing), for a quick introduction;
- A longer presentation deck [Annealing the Internet](https://docs.google.com/presentation/d/1wpx45K30QD2ZIDuS5WsuRGrbcCrxs56cvuhydWRIRiw/edit?slide=id.p#usp=sharing) with full details;

These tools are intended for public use — please share.
